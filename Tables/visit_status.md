# **Таблица Статусы посещений** (visit_status)
## Структура таблицы Статусы предоставления услуг
Таблица Статусы посещением является справочником возможных статусов:
- Запланировано
- Подтверждено
- Отменено
- Выполнено
- Перенесено
|Название атрибута|Тип данных|Описание атрибута|Ограничения|Обязательность|
|-|-------|---|-|-|
|status_id|uuid|Уникальный идентификатор записи|PRIMARY KEY|NOT NULL|
|status_name|varchar(50)|Название статуса |NOT NULL|
|notes|text|Описание статуса | |
|created_at|timestamp|Дата создания записи| |NOT NULL|
|updated_at|timestamp|Дата обновления записи| |NOT NULL|\
## Создание индексов для таблицы Статусы посещений 
 #### Простой индекс
 ```
 create index idx_name
on visit_status (status_name)
 ```
 Создание индекса для улучшения производительности при происке статуса по названию.
