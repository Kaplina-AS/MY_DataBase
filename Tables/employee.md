# **Таблица Мастера** (employee)
## Структура таблицы Сотрудники 
Таблица  Мастера  содержит основную информацию о сотрудниках салона.  
|Название атрибута|Тип данных|Описание атрибута|Ограничения|Обязательность|
|-|-------|---|-|-|
|id|uuid|Уникальный идентификатор записи|PRIMARY KEY|NOT NULL|
|last_name|varchar(255)|Фамилия| |NOT NULL|
|first_name|varchar(255)|Имя| |NOT NULL|
|middle_name|varchar(255)|Отчество| | |
|birth_date|date|Дата рождения| |NOT NULL|
|phone|varchar(20)|Номер телефона| | |
|email|varchar(50)|Адрес электронной почты| | |
|notes|text|Примечание| | |
|hire_date|date|Дата трудойстройства сотрудника| | |
|specialization_id|uuid|Идентификатор специализации сотрудника| FOREIGN KEY|NOT NULL|
|created_at|timestamp|Дата создания записи| |NOT NULL|
|updated_at|timestamp|Дата обновления записи| |NOT NULL|\
 ## Создание индексов для таблицы Сотрудники 
 #### Составной индекс
 ```
 create index idx_fullame
on masters (last_name, first_name)
 ```
 В базе данных поиск по имени и фамилии может получить преимущество от составного индекса по  двум столбцам - last_name и first_name - позволит найти все необходимые строки за один проход, избегая повторного обращения к таблице
