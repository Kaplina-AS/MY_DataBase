# Посчитать кол-во очков по всем игрокам за текущий год и за предыдущий
1. Создадим новую таблицу БД
```
CREATE TABLE statistic(
player_name VARCHAR(100) NOT NULL,
    player_id INT NOT NULL,
    year_game SMALLINT NOT NULL CHECK (year_game > 0),
    points DECIMAL(12,2) CHECK (points >= 0),
    PRIMARY KEY (player_name,year_game));
    ```
2. Заполним таблицу statistic данными

```
INSERT INTO
    statistic(player_name, player_id, year_game, points)
VALUES
    ('Mike',1,2018,18),
    ('Jack',2,2018,14),
    ('Jackie',3,2018,30),
    ('Jet',4,2018,30),

```

3. Запрос суммы очков с группировкой и сортировкой по годам
```
select year_game,SUM(points) as total_point
	from statistic
	group by year_game
	order by year_game
```

4. cte показывающее тоже самое

```
with statistic (year_game, points) as
	(select year_game,SUM(points) 
	from statistic
	group by year_game)
	select year_game, points
	from statistic
	order by year_game;
 ```
 >![Результат 2](/DataBase/select1.png)

 5. Используя функцию LAG вывести кол-во очков по всем игрокам за текущий код и за предыдущий
 ```
 select sum(points), year_game, LAG(sum(points)) OVER(order by year_game asc) as last_points
from public.statistic
group by year_game;
```
